## 📝 主な作品

### 【Voice be Chord】
**🏆 Laval Virtual 2025 出展作品**

「正確なピッチで和音を鳴らすと、倍音が発生する」という現象を再現し、音楽経験のない人でも「コーラス倍音の奇跡」を体験できるVR作品です。

**技術スタック:**
